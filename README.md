# slotmutoscope

Live Solana mainnet as a **Victorian mutoscope** (hand-crank flip-card peep viewer).

The crank advances with the slot clock. Flip cards glimpsed through the peephole are recent txs — tint by program family. Crank heat / motion smear ≈ fee pressure. Torn or jammed cards ≈ failed txs. Close the shutter (or Space) to freeze a strip.

Not an explorer. Not a dashboard. Not a newspaper.
